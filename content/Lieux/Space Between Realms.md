# Space Between Realms

Plan intermédiaire où débouche le **portail** de la [[Clock Tower]]. Dénomination informelle : **« plan astral »** (aussi « plaine astrale »).

- **Temps dilaté** : **1 an ici = 40 ans** sur le plan matériel (un repos long de 4 jours = 160 jours).
- [[Prof. Oupsius]] y trouve le groupe ; il **rouvre le portail**.

## Historique
- **[[Séance 2026-04-20 — Clock Tower et Modrons|2026-04-20]]** : atteint via le **portail tournant** de l'obélisque de la [[Clock Tower]] (qui alterne entre la plaine élémentale, le Dream Land et cet endroit) — après des **golems de terre** venus d'une autre plaine, une **voix** dit « **suffit de jouer** » → le groupe est **transporté** ici.
- **[[Séance 2026-04-30 — Le Far Dweller|2026-04-30]]** : combat contre le **[[Far Dweller]]** (*Mastermind*). Le groupe subit un **TPK** (tout le monde *down*).

> [!warning] La mort des [[Les Hazebreakers|Hazebreakers]] les envoie aux [[Shadow Lands]]
> Leur **mort (TPK)** face au Far Dweller **dans le Space Between Realms** les transporte dans l'au-delà — voir [[Séance 2026-05-11 — Shadow Lands]].

- **[[Séance 2026-05-18 — Victoire sur le Far Dweller|2026-05-18]]** : le **[[Far Dweller]]** est finalement **vaincu** (cristal de **délirium** trouvé dans son corps par [[Prof. Oupsius]]) ; Oupsius **rouvre le portail** → retour à la [[Clock Tower]].
