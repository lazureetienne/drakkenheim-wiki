# Sending (sort)

Sort de **communication à distance** utilisé pour contacter des alliés.

- ⚠️ **Ne pas utiliser dans le *haze*** (cf. [[Eldrich Runeweaver]], contactable via *sending stone*).
- Effet dangereux observé : [[Prof. Oupsius]] tente un *Sending* et devient **incapacité / fou** ; *Lesser Restoration* ne suffit pas à le sauver.

- [[Eldrich Runeweaver]] · [[Prof. Oupsius]]
